# Adv Dip Gradshow 2026

Website for the Animation and Game Art graduating class of 2026, featuring 21 students.

## Installation

### Prerequisites

- node >= 24.13.0
- npm >= 11.6.2

### Install Guide

First, clone the repository:
```bash
git clone https://github.com/liobrton/adv-dip-gradshow2026.git
```

Next, install any required packages:
```bash
npm i
```

Finally, build the site:
```
npm run dev
```

When releasing for production, build using ``npm run build`` instead of ``npm run dev``.
